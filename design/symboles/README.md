# Symboles conceptuels par livre

Cinq symboles vectoriels (SVG), un par livre. Chacun reprend le motif manifeste
de la couverture et la couleur d'accent du livre, réutilisable en page de partie
ou en exergue de section.

| Fichier | Livre | Motif |
|---------|-------|-------|
| `symbole-livre-01.svg` | Beyond the Firewall | Frontière traversée (ligne interrompue + flux de passage) |
| `symbole-livre-02.svg` | The Human Single Point of Failure | Nœud critique (réseau convergeant vers un nœud unique) |
| `symbole-livre-03.svg` | The Complexity Trap | Graphe densifiant (maillage clair → enchevêtrement) |
| `symbole-livre-04.svg` | The Age of Operational AI | Transition humain → système → agent |
| `symbole-livre-05.svg` | The Operator's Last Job | Opérateur relayé (silhouettes qui s'effacent) |

## Conventions

- `viewBox` 2:1 (`0 0 200 100`), fond transparent (la page fournit l'off-white `#F7F5F0`).
- Trait fin `1–1.6` ; palette : gris acier `#5A6B7A` (structure), couleur d'accent
  du livre (concept principal), turquoise `#1CB5A0` (marqueur de seuil / signature).
- Labels en Sora, taille ~7–8.
- Jamais d'ordinateurs, cadenas, circuits imprimés, code décoratif (charte §1).

## Correspondance couverture

Chaque `symbole-livre-NN.svg` est la version large du motif embarqué dans
`../couverture-livre-NN.svg`. La couverture full-bleed (152×229 mm) intègre le
symbole en bandeau bas ; ce fichier est la version isolée et agrandie.
